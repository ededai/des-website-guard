**A. reporters/evidence.py (new)** - the single pipeline boundary for evidence formatting (C-EVID).

`humanize(ev, _depth=0) -> str`
- None / "" -> ""; str -> stripped as-is.
- dict -> at depth 0 `"; ".join(f"{k}: {humanize(v, _depth+1)}")`; at depth >= 1 use `f"{k}={...}"`
  so nested rows read `state=focus, color=rgb(128,0,32)`.
- list/tuple -> `"; "` join at depth 0, `", "` deeper, capped at 3 items with a trailing `" (+N more)"`.
- anything else -> `str(ev)`.
- Final pass at depth 0: collapse whitespace, truncate to 1800 chars with an ellipsis.
- Add `_REPR_MARKERS = ("{'", "': ", '"}', "[{")`. At depth 0, if any marker survives in the output,
  strip `{}[]'"` from it rather than shipping a repr. This is the systemic guarantee: a check that
  starts returning a new dict shape can never regress the alert text again.

`escape_html(s) -> str` = `html.escape(str(s), quote=False)`.
